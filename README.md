# 🚀 Ultimate Task Manager (My Organizer)

A premium, feature-rich web-based Task Manager application. This project takes the standard "To-Do List" concept and elevates it with advanced features, dynamic styling, and absolute ease-of-use directly in the browser!

## ✨ Features Supported

- **🌖 Dark & Light Mode Support**: Instantly swap between a gorgeous Apple-styled frost-glass light theme or an immersive glowing neon dark theme. Your preference is saved instantly!
- **⚡ Task Prioritization**: Add new tasks sorted automatically by their urgency (`High`, `Medium`, `Low`). High-priority items stand out with visual cues and filter dynamically to the top by default.
- **🤏 Intuitive Drag & Drop**: Easily reorganize and reprioritize your day seamlessly by dragging your tasks smoothly into any position.
- **🔍 Intelligent Live Search**: Filter through tens or hundreds of saved tasks in real-time as you type using the fast search bar.
- **🏷️ Status Filtering**: Single-click toggles that filter your view between `All`, `Pending`, and `Done` states.
- **💾 Local Storage Persistence**: Your entire session—from your chosen theme to all active tasks and their state—is stored directly in your browser without requiring an external database.
- **🔔 Desktop Notifications**: Experience that hit of dopamine when a native browser pop-up congratulates you upon finishing a task.
- **⏱️ Time Tracking**: Every new task tracks and logs the exact time it was created.

## 💻 Tech Stack
- **Structure:** Vanilla `HTML5`
- **Styling:** Vanilla `CSS3` (CSS Variables, Flexbox, Animation Keyframes, Glassmorphism)
- **Logic:** Vanilla `JavaScript` (ES6+, DOM Manipulation, LocalStorage, Web Notifications API)
- **Assets/Libraries:** [Sortable.js](https://sortablejs.github.io/Sortable/) (Drag and Drop Engine), [Ionicons](https://ionic.io/ionicons) (Vector Icons)

## 🛠️ How to run locally

Running this site is incredibly easy since it relies purely on client-side vanilla technologies! 

1. **Clone the repository:**
   ```bash
   git clone https://github.com/somu2277/task-manager.git
   ```
2. Navigate into the directory and open `index.html` in your favorite modern browser (Chrome, Edge, Firefox, Safari).
3. Start adding your tasks and customizing your day! No Node dependencies or servers required.
